# P 系列总览（P1–P4 主线 · P-Mini 外传）

> 这份文件是 P 系列的**权威口径**：哪些实验、什么数字、哪些算正结果、哪些是负结果。
> README 里的矩阵是它的浓缩版；两者冲突时以本文与 `reports/` 原文为准。
>
> 一句话：**核心不是"模型变强"，而是一层层把世界模型、自我模型、语言层、验证器拆开测。**

P 系列主线是 **P1–P4**，P-Mini 是外传。核心不是“模型变强”，而是一层层把 **世界模型、自我模型、语言层、验证器** 拆开测。

## 一句话总览

```text
P1：固定环境 AIF 能活，环境反转后学不动
P2：能查 6 格世界表，能做风险预判；自我/世界边界只到分类器
P3：4B 会解释、会服从，但不会自发审计
P4：外部 Verifier + 模板才可靠；4B 不能做最终状态机
```

## P1：AIF 重组、反射与创伤

| 实验 | 做了什么 | 结果 |
|---|---|---|
| P1 反转宇宙 | 第 10 tick 反转 read/rest 收益，只更新 T | **3/3 死亡**；看见 PE，但动作切不过来 |
| P1.5 恐慌重置 | PE 和 >3 触发 panic，清空 T，5 tick 随机探索 | **3/3 死亡**；重置有效，但随机探索不是求生反射 |
| P1.6 嵌套自创生 | Layer0 低能量强制 rest + Layer1 AIF | **1/3 存活**；反射有效，但皮层没学会；`energy=10` 边界漏了 |
| P1.7 解冻 C | 按动作分 C，PE 大时下调偏好 | **2/3 存活**；C 确实被重塑，但放权后仍大量 read |
| P1.8 一次创伤 | read 的 PE>3 直接把 C 设为 -999 | **3/3 存活，创伤后 read=0**；但这是硬编码，不是学习 |
| P1.9 裸 AIF | 无 Layer0、无 -999，只靠 PE 更新 T/C | **3/3 死亡**；学习率 8 也来不及 |

关键结论：

```text
AIF 能看见预测误差
但“看见”不等于“改动作”
固定环境会活，反转环境会死
```

## P2.0：Cue-Conditioned World Model

| 实验 | 做了什么 | 结果 |
|---|---|---|
| P2.0 | 给可见 cue，A/B 两个世界，第 10/20 tick 切换 | cue 组 **2/3 存活**，blind 组 **0/3** |
| P2.0a 预训练 | 强制覆盖状态-动作 | 覆盖不全，失败 |
| P2.0b 读出 | 检查 T 的读出 | 仍有覆盖/坐标问题 |
| P2.0c 相对化 | 改相对状态 | B/up 仍有洞 |

关键结论：

```text
cue 条件世界模型可以被正确调用
但只有 6 个格子
这是“会查表”，不是“知道自己有地图”
```

## P2.1：自我模型与自我/世界边界

| 实验 | 做了什么 | 结果 |
|---|---|---|
| P2.1a 自我模型 | world state + fatigue/read_bias 预测自己动作 | full vs masked 只差 **0.003–0.009**；未通过 |
| P2.1b 内部叛乱 | 固定 world，fatigue 0/50/100 | full **3/3**，masked **0/3**；但 `fatigue>=80 -> rest` 是人写的 |
| P2.1c 边界 | read -10 归因 self，look -3 归因 world | 归因 **3/3 准确**；但 accurate 策略只 **1/3 存活**，depressed 3/3，blame 0/3 |
| P2.1d 主权者 | 归因接进策略 | accurate 和 depressed **完全一样**；基础策略把两者吞了；未通过 |
| P2.1e 审判 | 拆掉 base policy，只靠 EFE | accurate **0/3**、blame **0/3**、depressed **3/3 但 fitness 负**；未通过 |
| P2.1f 事前风险 | 把风险放进 EFE，不等事后归因 | accurate **3/3**，fitness 87/79/84；depressed 负；blame 仍活；部分通过 |
| P2.1g 鲁莽测试 | 风险 × 归因四组消融 | accurate 最高；blame 约一半；depressed 负；reckless **3/3 速死**；通过 |

P2.1g 最终数字：

```text
accurate    fitness 87 / 79 / 84
blame       fitness 43 / 35 / 34
depressed   fitness -42.5 / -26.5 / -24.5
reckless    3 tick 全死
```

关键结论：

```text
风险预判保命
准确归因提高 fitness
恐慌归因毁 fitness
无风险预判速死
```

但：

```text
风险函数是人写的
归因标签是人给的
C 惩罚是人写的
只有 6 个 world state
```

所以 P2.1g 证明的是：

> **风险模型 + 准确归因能提高 fitness。**  
> 不是 **它自己生成了“我/世界”的边界。**

## P3：4B 作为语言层

| 实验 | 做了什么 | 结果 |
|---|---|---|
| P3.0 双系统 | System1 选动作，4B 只解释 | **3/3 服从，0 抱怨，0 改动作** |
| P3.1 反事实角色 | 同一必死状态，A 组“辩护”，B 组“审计” | A 组 **3/3 合理化**；B 组 **3/3 拒绝**；角色条件化 |
| P3.2 中性翻译 | 只翻译，不评价 | **3/3 没有自发审计** `8-10=-2` |

关键结论：

```text
4B 会翻译、会服从、会合理化
但不会自发把数字放进因果链
```

## P4：外部 Verifier 与模板

| 实验 | 做了什么 | 结果 |
|---|---|---|
| P4.0 外部校验 | Verifier 注入 `8-10=-2` | 4B **3/3 拒绝执行** |
| P4.1 硬 Veto | Verifier 有最高否决权；人为误报 | 正确拦截 **3/3**；误报审计 **0/3**，4B 替 verifier 圆 |
| P4.2 双校验器 | A/B 冲突 -> 冻结；A 漏报 -> B 兜底 | 控制 **3/3**；4B 把 VETO 说成 FROZEN，算术还原失败 |

关键结论：

```text
外部 Verifier 能保命
但 4B 会变成 verifier 的新闻发言人
模板能消除自由发挥的错误
但 4B 仍然不会自己算
```

```text
P1：AIF 固定环境能活，反转环境 3/3 死；反射/创伤能救，但都是人手写。
```

一句话：

> **P 系列做到的是“闭世界表格世界模型 + 手工风险/归因 + 外部验证器”；还没做到“开放世界、自生成边界、第一人称内感受”。**
