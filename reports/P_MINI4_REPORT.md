## 4. 关键发现

### 发现 1：I 的记忆先验太弱，等于没有

```text
I fixed = G fixed：死亡 4%，到达 96%
```

I 有 17 次记忆命中，  
但动作选择没有被改变。

这不是“记忆无效”，是“记忆权重低到不影响决策”。

### 发现 2：J 的特征记忆没有空间绑定，变成了全局恐惧

J 的逻辑是：

```text
死亡 -> 特征记忆：trap 危险
-> feature_prior = 0.6
-> 给所有相邻格都加同样的风险
```

问题是：

```text
它不知道哪一格危险。
它只知道“陷阱这个东西危险”。
```

于是它不是在避开陷阱，  
而是在给所有移动加一层普遍的恐惧。

### 发现 3：预测误差校验没有救回来

```text
J random：pred_errors = 241
J fixed：pred_errors = 259
```

它确实检测到了“旧记忆和当前雷达冲突”，  
也确实把 feature_prior 降了。

但降完之后：

```text
它还是不知道陷阱在哪一格。
```

预测误差只能降低“全局恐惧”，  
不能恢复“空间定位”。

### 发现 4：J 没有能量死，但陷阱死更多

```text
J random：陷阱死 22%，能量死 0%
G random：陷阱死 3%，能量死 0%
```

J 的时间更长（18.18 回合），  
但它不是“更谨慎地绕开”，  
而是“带着全局风险慢慢走，最后撞上”。

## 5. 这算“从经验中提取教训”吗？

**不算。**

J 确实做到了：

```text
不记绝对坐标
记忆衰减
预测误差校验
```

但它没有做到：

```text
把“trap 危险”绑定到“当前哪一格是 trap”
```

所以它学到的不是：

```text
这个世界的陷阱在哪里
```

而是：

```text
世界很危险
```

这不是经验。  
这是**没有空间索引的焦虑**。

---

## 6. 为什么这个负结果重要

它说明：

> **特征记忆如果没有空间绑定，比绝对坐标记忆更糟。**

绝对坐标记忆至少知道：

```text
上次死在这里
```

特征记忆只知道：

```text
trap 会杀人
```

而当前雷达已经知道：

```text
这一格现在有高风险信号
```

G 已经把这件事实时用上了。  
J 的“trap 危险”没有增加任何新信息，  
只增加了全局风险权重。

### 这个沙盒的根本限制

当前世界里，陷阱的可观测特征只有：

```text
相邻雷达信号
```

没有颜色、形状、地形、声音等可泛化特征。  
所以“特征记忆”没有真正的特征可记。

它要么退化成：

```text
绝对坐标
```

要么退化成：

```text
全局恐惧
```

J 走的是后者。

## 7. 下一步

### 7.1 先给陷阱一个可观测特征

```text
外观：红色方块 / 裂纹 / 特殊地形
```

然后在死亡记忆里记录：

```text
特征向量：红色 + 裂纹 + 靠近补给站
```

而不是：

```text
坐标 (3,2)
```

### 7.2 特征必须能匹配当前感知

```text
当前雷达看到红色裂纹
-> 匹配“红色裂纹 = trap”
-> 提高该格风险
```

否则“特征记忆”没有落点。

### 7.3 记忆要有空间不确定性

不是：

```text
(x,y) 一定危险
```

而是：

```text
(x,y) 附近可能有 trap，置信度 0.6
```

### 7.4 预测误差要能更新“特征-后果”映射

不是只降低全局权重，  
而是：

```text
红色裂纹 -> 上次是 trap
这次红色裂纹 -> 安全
-> 降低“红色裂纹 = trap”的置信度
```

## 8. 结论

```text
I vs G：无增益，固定地图完全一样
J vs G：随机地图显著更差
J 的预测误差校验：发生了，但救不了空间缺失
```

所以：

> **P-Mini 4.0 没有证明“记忆驱动的自我模型演化”。**  
> **它证明了：没有空间绑定的特征记忆，是一种全局焦虑，不是经验。**

一句话：

> **G 活在当下；I 抱着旧坐标但不敢用；J 记住了“陷阱很危险”，却不知道陷阱在哪。**  
> **这不是从经验中学习，这是把恐惧撒在了整张地图上。**
