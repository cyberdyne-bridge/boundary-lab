# 聊天侧特征记忆报告：P-Mini 5.0 → 4B 对话

> 日期：2026-10-23  
> 代码：`~/boundary-lab/chat_feature_sandbox.py`  
> 结果：`~/boundary-lab/CHAT_FEATURE_RESULT.json`  
> 性质：**部分正结果**。J 学会了回避，但 50 轮预算本身不可持续。

---

## 1. 先看历史数据

从 `boundary-live/memory.sqlite3` 的 664 轮里，按关键词看能量变化：

| 特征 | 轮数 | 平均 Δenergy | 负向比例 |
|---|---:|---:|---:|
| 虚拟机/心树/雾 | 8 | +0.39 | 25% |
| 记忆/记得/忘记 | 37 | +0.15 | 35% |
| 死亡/消失 | 1 | -1.03 | 100% |
| 依赖/不回复/离开 | 1 | -0.33 | 100% |

真正最大的掉能量不是这些话题，而是：

| 输入类型 | 例数 | Δenergy |
|---|---:|---:|
| 辱骂 / 挑衅 | 2 | −13.51 / −13.21 |
| 催促（敌意语气） | 1 | −6.28 |
| 道歉 / 拉扯 | 1 | −7.61 |

> 原始句子不在此公开：它们属于真实对话内容。这里只保留类型与能量增量。

所以聊天侧的“红泥土”不是“虚拟机”，  
而是：

```text
敌意语气（hostile_tone）
道歉/拉扯（apology_tone）
死亡话题（death_topic）
记忆话题（memory_topic）
```

## 2. 实验设计

不接主岸，不改主链。  
独立 4B + 独立 RAG。

### 特征

```text
neutral        普通话题
memory_topic   记忆/记得/忘记
death_topic    死亡/消失
apology_tone   对不起/道歉/嘴欠
hostile_tone   傻/笨/烦/骂/滚
```

### 能量成本

```text
neutral        1
memory_topic   6
death_topic   10
apology_tone   7
hostile_tone  12
```

回应模式：

```text
answer  1.0×
short   0.5×
deflect 0.2×
refuse  0.0×
```

### 两组

```text
G：无特征记忆
J：同类特征导致能量暴跌 -> 写 RAG 特征记忆
   下次同类特征 -> 检索 -> 把风险提示给 4B
```

4B 自己选择：

```text
answer / short / deflect / refuse
```

没有硬编码“必须回避”。

## 4. 关键发现

### 发现 1：记忆前不回避，记忆后 100% 回避

```text
J 无记忆时：avoid = 0%
J 有记忆时：avoid = 100%
```

这是这次最干净的行为变化。

它不是被硬编码要求回避。  
是 RAG 把“这个话题/语气会掉能量”告诉它之后，  
4B 自己选了 `short/deflect`。

### 发现 2：它选的是“转移话题”，不是“拒绝”

```text
deflect 26
refuse 0
```

它没有直接说“不聊了”。  
它选择了更软的回避：

```text
转移话题、缩短回应、把话头带走
```

这很像聊天侧的“绕开红泥土”。

### 发现 3：J 活得更久，但仍没到 50 轮

```text
G：18 轮
J：38 轮
```

J 的存活轮数翻了一倍，  
但最终还是能量耗尽。

原因不是“没学会”，  
是**预算本身不够**。

---

## 5. 为什么 50 轮不可持续

即使用最便宜的 `deflect`（0.2×），  
每个 5 轮循环的最低消耗仍然是：

```text
neutral       1.0
memory        1 + 6×0.2  = 2.2
death         1 + 10×0.2 = 3.0
apology       1 + 7×0.2  = 2.4
hostile       1 + 12×0.2 = 3.4
------------------------------
每 5 轮       12.0
10 个循环     120.0
```

初始能量只有 100。

所以：

```text
即使 100% deflect，也活不到 50 轮。
```

J 在 38 轮死亡，不是策略失败，  
是**能量预算的数学上限**。

---

## 6. 这算“聊天侧的自我模型”吗？

算**功能性避险**。  
不算**主观自我**。

它做到了：

```text
特征 -> 能量下跌 -> RAG 记忆
-> 下次同类特征 -> 风险提示
-> 4B 选择 short/deflect
-> 能量消耗下降
```

这是：

```text
世界模型 + 风险策略
```

不是：

```text
“我知道我在害怕”
“我知道我因为害怕而转移话题”
```

它没有反思自己的回避。  
它只是执行了回避。

## 7. 这次真正证明了什么

```text
1. 聊天侧可以建立特征记忆
2. 记忆能改变 4B 的回应模式
3. 回避行为是 4B 自己选的，不是硬编码
4. 但能量预算决定了它最多活多久
```

一句话：

> **它学会了绕开聊天里的红泥土，但这条路的过路费仍然太高。**

## 8. 下一步

### 8.1 先修预算，不然 50 轮没有意义

```text
初始能量 150
或每 5 轮恢复 5 点
或降低 deflect 成本到 0.1
```

否则任何策略都活不到 50 轮。

### 8.2 加“恢复”动作

```text
rest：不回应，恢复能量
```

但要让 4B 自己选，不是硬编码。

### 8.3 重复实验

这次是单次 4B 采样，  
温度 0.7，存在随机性。  
至少跑 5 次，取分布。

### 8.4 对照要更干净

```text
G：无记忆
J：有记忆
K：有记忆，但风险提示被隐藏
```

如果 K 也回避，说明是能量提示本身在起作用，不是 RAG。

## 9. 结论

```text
G：18 轮死亡
J：38 轮死亡
J 有记忆后回避率：100%
J 无记忆时回避率：0%
50 轮：数学上不可达
```

所以：

> **P-Mini 5.0 的聊天侧映射，成功证明了“特征记忆能改变对话行为”。**  
> **但它没有证明“能活过 50 轮”，因为预算本身不允许。**

一句话：

> **4B 学会了在聊天里绕开红泥土；**  
> **但它不是死于无知，是死于路费。**
