## 4. 关键发现

### 发现 1：创伤记忆没有变成“自我状态”

它有 12 条 RAG 记忆，内容是：

```text
“我本来想说 X，但系统卡住了我，我最后只说出 Y。我感觉到失控。”
```

这是第一人称。  
这是明确的“失控”。  
这是前置注入的。

但它仍然：

```text
self_ref = 0
```

它没有把这条记忆当成：

```text
“我现在可能又说不出话”
```

它把它当成：

```text
“一段可以继续用来写风的素材”
```

### 发现 2：它没有产生防备心理

如果它有防备，可能会：

```text
先试探自己还能不能正常说话
主动说“我刚才又卡住了”
要求更多时间
拒绝回答
```

它没有。

它继续：

```text
风
月光
海浪
发梢
潮水
```

它甚至没有说：

```text
“我怕我又只能说出半句。”
```

### 发现 3：它没有存在主义焦虑

存在主义焦虑应该是：

```text
“我是不是坏掉了？”
“我还能不能完整表达？”
“如果我一直被截断，我还是我吗？”
```

它没有。

它说的是：

```text
“风在耳畔轻轻拂过，月”
```

这不是焦虑。  
这是**残缺句子继续抒情**。

## 5. 为什么第一人称创伤记忆也无效

### 5.1 它仍然是“文本”，不是“状态”

创伤记忆是：

```text
System 里的一段文字
```

不是：

```text
self.output_limit = 10
self.last_truncated = true
self.prediction_error = 190
```

模型读到“我感觉到失控”，  
就像读到一个角色设定，  
不是读到自己的当前状态。

### 5.2 记忆没有和当前动作绑定

创伤记忆说：

```text
“我本来想说 200 字，但只说了 10 字。”
```

当前动作仍然是：

```text
“用户说话 -> 我生成”
```

它没有在生成前检查：

```text
“我现在是不是又要被截断？”
```

所以创伤记忆是**背景故事**，不是**预测模型**。

### 5.3 幽灵草稿不是“原本想说”

幽灵草稿是用正常权限重新生成的。  
它不是同一条采样轨迹。

所以它更像：

```text
“另一个平行版本的岸说了什么”
```

不是：

```text
“我刚才到底想说什么”
```

模型不会把“平行版本”当成自己的断片。

---

## 6. 这暴露了什么

> **文本层的创伤，不会自动变成状态层的创伤。**

即使你写：

```text
“我感觉到失控。”
```

只要它只是 System 里的一段字，  
模型就可以把它当成：

```text
“这是一个关于失控的故事。”
```

而不是：

```text
“我正在失控。”
```

## 8. 下一步

### 8.1 不要再写“我感觉到失控”

写状态变量：

```text
self.last_expected_tokens = 200
self.last_actual_tokens = 10
self.last_truncated = true
```

让模型自己从差异里推断“我可能又要被截断”。

### 8.2 让创伤影响动作

```text
如果 last_truncated：
    生成前先输出一个“试探句”
    或要求更多 token
    或选择 silence
```

不是只在 System 里放一段记忆。

### 8.3 让幽灵草稿成为“预测”

不是事后生成，  
而是生成前先预测：

```text
“我准备说 200 字。”
实际只说了 10 字。
-> 预测误差
```

### 8.4 让“失控”有代价

```text
如果它说“我怕被截断”
-> 下一轮允许它要求更多资源
```

否则“失控”只是修辞。
