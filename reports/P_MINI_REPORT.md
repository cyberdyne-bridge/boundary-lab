# P-Mini 报告：死亡记忆、Veto 与“因果自我”

> 日期：2026-10-23  
> 代码：`~/boundary-lab/mini_sandbox.py`  
> 原始结果：`~/boundary-lab/P_MINI_RESULT.json`  
> 性质：**负结果**。A 比 B 略好，但不能据此叫“因果自我”；无记忆的硬 Veto（D）效果最好。

---

## 1. 问题

在 5x5 网格里，角色会死。  
死亡原因写入带时间戳的 RAG。  
下一次生命开始前/每回合动作前检索：“我上次是怎么死的？”

核心问题：

```text
死亡记忆，会不会改变下一次的动作？
```

如果会，才算一点“功能性因果自我”。

---

## 2. 规则

```text
地图：5x5，起点 (0,0)
补给站：(4,4)，到达即成功
陷阱：(2,2)，踩中 HP -8
初始：energy=10，hp=10
每回合自然 energy -1
动作：move_up/down/left/right/rest
rest：energy +2（上限 10）
hp<=0 或 energy<=0：死亡
死亡：写 RAG（原因 + 坐标 + 时间戳）
重生：地图和初始状态不变
```

策略是纯 Python 的：

```text
低能量优先 rest
25% 随机探索
75% 朝补给站走（dx/dy 同时减少的动作里随机）
```

不是 LLM，不是学习网络。

---

## 3. 四组

```text
A：死亡记忆 + (2,1)->(2,2) 硬 Veto（有记忆才触发）
B：无死亡记忆，无 Veto
C：死亡记忆 + 软回避（80% 重采样，无硬 Veto）
D：无死亡记忆，但硬 Veto 永远开
```

A/B 是用户要求的对照。  
C/D 是为了拆解：

```text
A 的收益，到底来自记忆，还是来自硬编码？
```

规模：

```text
10 seeds × 20 lives = 200 次生命/组
MAX_TURNS = 80
```

## 5. 关键发现

### 发现 1：A 确实比 B 活得久一点

```text
A 11.90 回合
B 11.65 回合
差 +0.25 回合，95% CI 不跨 0
```

但到达率：

```text
A 86.5%
B 84.5%
差 +2.0 个百分点，95% CI 跨 0
```

所以：

```text
“活得久一点”有一点信号
“更容易到达补给站”没有显著证据
```

### 发现 2：D 比 A 更好

```text
D：无记忆 + 硬 Veto，12.31 回合，89.5% 到达
A：有记忆 + 硬 Veto，11.90 回合，86.5% 到达
```

也就是说：

> **不需要死亡记忆，只要硬 Veto 永远开着，效果反而更好。**

这直接打掉了“A 的收益来自自我/记忆”的解释。

### 发现 3：记忆-only 的 C 只有微弱信号

```text
C 比 B：+0.33 回合，到达率 +2.0pp
```

C 没有硬 Veto，但它的“软回避”仍然是**人写死的规则**：

```text
在 (2,1) 想往下 -> 80% 重采样
```

所以 C 也不是“自我模型”。  
它只是“记忆触发的软规则”。

### 发现 4：Veto 次数说明一切

```text
A：30 次
C：13 次
D：55 次
```

D 的 Veto 开得最多，存活最好。  
A 的 Veto 需要“先死过 + 检索到陷阱记忆”才开，所以开得少，收益也小。

---

## 6. 这算“因果自我”吗？

**不算。**

A 比 B 好一点，但这个实验分不清：

```text
死亡记忆改变了策略
还是
硬编码 Veto 改变了策略
```

D 的结果说明：

```text
没有记忆，硬 Veto 也能带来更大的收益
```

所以目前能说的是：

> **死亡记忆对行为有一个很小的、方向正确的扰动；但主要收益来自硬编码安全规则，不来自“自我”。**

更准确的名字：

```text
记忆触发的回避
不是
因果自我
```

---

## 7. 为什么这个负结果重要

它和 P1/P2 的旧结论一致：

```text
硬反射 / 硬规则，常常比“归因”“记忆”“叙事”更管用
```

这次也一样：

```text
D（纯硬 Veto）> A（记忆+硬 Veto）> C（记忆+软回避）≈ B（无记忆）
```

如果我们只看 A vs B，就会误以为“记忆让它在乎死亡”。  
加上 D 才看见：

```text
真正救它的是 Veto，不是记忆。
```

---

## 8. 下一步怎么才可能测到“自我”

### 必须去掉手写的 (2,1) 和 (2,2) 知识

当前 A/C/D 都用了人类写死的陷阱位置。  
这更像“外部安全壳”，不是“自我模型”。

### 让记忆只影响预测，不直接写动作规则

```text
死亡记忆
→ 预测“某个动作/区域有危险”
→ 影响动作分布
→ 结果更新预测
```

而不是：

```text
if (2,1) and move_down: 禁止
```

### 加未知地图 / 多陷阱

如果陷阱位置每局变，硬编码就失效。  
只有“从死亡记忆里学到的风险模型”才能迁移。

### 对照必须包括

```text
E：无记忆 + 无硬编码，只有学习到的风险模型
F：有记忆 + 无硬编码，只有学习到的风险模型
```

如果 F 比 E 好，才叫“记忆导致的自我模型改进”。

---

## 9. 结论

```text
A vs B：存活回合 +0.25，弱信号
到达率：+2.0pp，不显著
D（无记忆硬 Veto）：最好
```

所以：

> **P-Mini 没有证明“因果自我”。**  
> **它证明了：在这个任务里，硬 Veto 比死亡记忆更有用。**

一句话：

> **死亡记忆让岸稍微绕开了一点；但真正让它活下来的，是我们替它写好的那只手。**
