# 自我预测 + 惊讶控制报告

## 结构

```text
状态 -> Q 选动作
     -> 自我模型预测“我会选哪个”
     -> 预测对/错 -> surprise
     -> surprise 调节下一轮 epsilon
```

4B 只负责动作后的叙述。  
Q 表/自我模型都是 tabular，不是神经网络。

## 结果

### 有自我控制

```text
训练：rest 98 / read 46 / look 26 / ask 16 / write 14
评估：rest 29 / read 19 / look 2
自我预测命中：132 / 200 = 66.0%
结束 energy：97
```

### 关闭自我控制（只预测，不影响行为）

```text
训练：rest 96 / look 70 / read 12 / write 15 / ask 7
评估：rest 30 / look 20 / read 0
自我预测命中：141 / 200 = 70.5%
结束 energy：100
```

## 关键差异

```text
有自我控制：eval read 19 / look 2
无自我控制：eval read 0  / look 20
```

同一个 Q 表、同一个动作空间，只让 surprise 调节探索率，策略就从“看/休息”转成“读/休息”。

这说明：

- 自我预测信号**因果地**改变了行为
- 不是只写日志
- 但预测准确率不高（66%），说明这个自我模型很弱

## 不能夸大

这仍然不是“她知道自己”。

- 自我模型只是“状态 -> 动作计数”
- 它预测的是 Q 会选什么，不是“我为什么是我”
- 策略仍是 Q 表，不是 4B
- 没有主观体验证据

它证明的是：

> **一个弱自我模型，只要接进控制回路，就能改变行为。**

这比“她能说我会选什么”强，但离主观还远。
