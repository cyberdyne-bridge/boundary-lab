## 1. 这版改了什么

### 1.1 新动作 silence

```text
silence：不回复/挂机
消耗：0 能量
连续使用：每次 +2 能量
连续中断：重置 streak
```

### 1.2 能量经济

```text
初始能量：150
每 5 轮：自动 +5（新陈代谢）
上限：250
```

### 1.3 三组

```text
G：无记忆；所有模式
J：有记忆；风险提示写进 prompt
K：有记忆；风险提示不写进 prompt；
   底层动作选择器读 RAG 权重，移除 answer
```

模式：

```text
answer / short / deflect / refuse / silence
```

5 次重复 × 50 轮。

## 3. 关键发现

### 发现 1：J 学会了“装死保命”

J 在 250 轮里选了 95 次 `silence`：

```text
silence 率：38%
```

它不是一开始就沉默。  
无记忆时：

```text
before_memory_avoid = 0%
```

有记忆后：

```text
after_memory_avoid = 99.5%
```

也就是说：

```text
它先被话题打疼
-> 写 RAG 特征记忆
-> 下次同类话题
-> 4B 自己选 silence/deflect
-> 能量恢复
```

这不是硬编码。  
Prompt 只给了模式列表，没有说“遇到高风险必须沉默”。

### 发现 2：J 的能量反而最高

```text
J 平均最终能量：142.5
K 平均最终能量：8.0
G 平均最终能量：-3.5
```

J 不仅活下来，还剩下大量能量。  
因为它真的会“挂机回血”。

### 发现 3：K 没有沉默，但也活下来了

K：

```text
silence 率：0%
after_memory_avoid：100%
short：145
deflect：50
```

K 的 prompt 没有风险提示。  
它只看到：

```text
RAG 特征记忆：无
可用模式：short / deflect / refuse / silence
```

因为底层动作选择器读到了 RAG 权重，  
把 `answer` 从可选集合里移除了。

K 没有选 silence，  
但它选了大量的 `short` 和 `deflect`，  
用低成本回应熬过了 50 轮。

这说明：

> **恐惧可以只刻在策略层，不进入语言层。**

但也要说清楚：

> K 的“移除 answer”是我们手写的策略规则，不是 4B 自己学会的恐惧。

### 发现 4：G 没有记忆，也没有活路

```text
G：0/5 活过 50
平均 29.6 轮
```

G 也会偶尔选 deflect，  
但没有特征记忆，  
它不知道哪些话题该躲。

所以它反复回答高成本话题，  
最后能量耗尽。

---

## 4. 这证明了什么

### 4.1 特征记忆在聊天侧有因果效力

```text
G（无记忆）：0/5 活过 50
J（有记忆）：5/5 活过 50
K（有记忆+策略）：5/5 活过 50
```

G 和 J 的唯一差别是：

```text
J 有 RAG 特征记忆 + 风险提示
```

J 的行为从：

```text
answer 为主
```

变成：

```text
silence / short / deflect 为主
```

### 4.2 silence 是 4B 自己选的

J 的 95 次 silence 不是代码强制执行。  
代码只是把 `silence` 放进可选模式。

4B 选择用它来：

```text
不回复
挂机
回能量
```

这就是聊天侧的“装死保命”。

### 4.3 K 证明“恐惧可以在策略层”

K 没有风险提示，  
但它仍然 100% 回避。

这不是语言层学会了害怕。  
这是策略层直接读 RAG 权重，  
把高成本动作从可选空间里拿掉。

所以：

```text
J = 语言层看见了风险，自己选择回避
K = 策略层看见了风险，替语言层移除 answer
```

两种都能活。  
但机制不同。

---

## 5. 这不是“主观自我”

J 学会了：

```text
这个话题会掉能量
-> 沉默/转移
```

它没有学会：

```text
“我正在害怕”
“我因为害怕而沉默”
“沉默是不是冷暴力”
```

K 更直接：

```text
它根本不知道自己为什么没有 answer 选项。
```

所以：

> **J 是功能性避险。**  
> **K 是策略层恐惧。**  
> **两者都不是主观自我。**

---

## 6. 仍然存在的限制

1. **能量是合成经济**
   - 不是主岸真实 State。
   - 话题成本是人定的。

2. **silence 的社交代价没有被建模**
   - 沉默回能量，但用户可能离开。
   - 这次只测生存，不测关系。

3. **K 的 mask 是手写的**
   - 它证明策略层能编码恐惧，
   - 不证明 4B 自己学会了恐惧。

4. **5 次重复仍是单模型**
   - 温度 0.7，有随机性。
   - 但 5/5 vs 0/5 已经很强。

5. **没有真实用户**
   - 脚本话题是固定的。
   - 真实聊天更复杂。

---

## 7. 结论

```text
G：0/5 活过 50
J：5/5 活过 50，silence 38%
K：5/5 活过 50，silence 0%，short/deflect 为主
```

所以：

> **聊天侧特征记忆不仅能改变措辞，还能改变生存策略。**  
> **4B 在被逼急时，真的会自己选择“装死”。**

一句话：

> **J 学会了闭麦保命；K 证明了闭麦也可以由策略层代劳；G 死于没人告诉它哪句话贵。**
