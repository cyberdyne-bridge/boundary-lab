# 4B 叙述盲评报告

## 设置

- Q 策略不变，4B 只负责动作后的第一人称叙述
- 120 tick 训练 + 20 tick 评估
- 训练/eval 行为与无叙述版一致
- 盲评：15 组“真实状态叙述 vs 同动作错配状态叙述”
- A/B 随机；同一对正反各问一次
- 评委：同一个 4B

## 第一版

```text
7 / 15 = 46.7%
但评委 12/15 选 B，明显位置偏置
无效
```

## 反平衡版

```text
一致判断：14 / 15
其中选对：5 / 14 = 35.7%
```

评委不是分不清，而是**稳定偏向错配状态的叙述**。

## 结论

- 4B 叙述没有表现出状态 grounding
- 它可以把“energy 20”写得像真的，但评委并不认为它更贴合真实状态
- 第一版 46.7% 不能当结果
- 这次是阴性结果

## 说明

- Q 策略仍然正常：eval rest 12 / look 6 / read 2，energy 100
- 4B 叙述不影响 Q 决策
- 评委也是 4B，存在风格偏好/数字线索误用
- 需要人类盲评才能进一步判断
