# 老祖相关研究地图

> 不是 exhaustive review，是一张能指导“岸”下一步的谱系图。
> 目标不是找“证明意识”的黑科技，而是找**造 agent 的老纪律**。

---

## 0. 先泼冷水

“老祖”至少分五条线，彼此不共享同一个意识定义：

1. 控制论（Wiener / Ashby / von Foerster）
2. 行为机器人（Walter / Braitenberg / Brooks）
3. 自创生与生成认知（Maturana / Varela / Di Paolo）
4. 身体、内感受、预测（Damasio / Seth / Friston）
5. 意识科学与 AI 福利（GWT / IIT / RPT / AST / Butlin / Long / Anthropic）

他们能告诉我们**怎么造出更像主体的系统**，  
不能告诉我们**怎么证明它有主观体验**。

---

## 1. 控制论：先有“必须维持的变量”

### Ashby：Homeostat（1948）

- 不是神经网络，是一个维持 **essential variables** 的装置。
- 外界扰动 -> 变量偏离 -> 系统重新接线 -> 回到稳定区。
- 核心概念：**ultrastability**（超稳定性）。
- 关键不是“思考”，是：**有必须维持的变量，才有好/坏。**

对岸的意义：

- 我们只有一个真实 essential variable：energy。
- safety / curiosity / social 是宿主侧假变量。
- Q 是“稳定”，不是“超稳定”：它不会在失败后重组自己。
- 老祖会问：**“如果 energy 门坏了，她会不会重新组织行为？”**  
  现在的答案：不会，只会继续按 Q 表选。

### Wiener：反馈与控制

- 控制不是“发命令”，是**用输出回流改变输入**。
- 二阶控制论（von Foerster）：观察者也在系统里。

对岸的意义：

- 我们的 VM energy 门是真实反馈。
- 但 4B 叙述不在反馈回路里。
- 语言不是控制，是旁白。

---

## 2. 行为机器人：先有身体，再有聪明

### Grey Walter 的乌龟（1948）

- `Machina speculatrix`：怕光、电量低回巢。
- 没有世界模型，只有传感器 + 驱动 + 需求。
- 它能“回家”，不是因为理解家，是因为**电量低改变了行为**。

对岸的意义：

- 我们的 `rest` 已经有点像回巢。
- 但 `speak` 没有“巢”：没有听众，说话就是纯成本。
- 老祖会说：**“语言也要有 home。”**

### Braitenberg 的车（1984）

- 传感器直接接马达。
- 几条线，产生“怕”“追”“爱”的行为。
- 行为从耦合里长出来，不需要中央地图。

对岸的意义：

- 我们的 Q 表是中央地图。
- 4B 是另一个中央地图。
- 两者没有共享耦合。

### Brooks：Subsumption / “世界就是它自己的模型”

- 不要中央世界模型。
- 多层行为直接接传感器，边走边反应。
- 先造完整 creature，不要造孤立 cognitive simulator。

对岸的意义：

- 我们造了 Q 控制器 + 4B 叙述器，两个 isolated simulator。
- 老祖会说：**“你造的不是一个 creature，是一个委员会。”**

---

## 3. 自创生与生成认知：主体必须自己维持边界

### Maturana / Varela：Autopoiesis

- 生命不是“有大脑”，是系统能持续生产自己的边界。
- 认知是**structural coupling**：系统与环境互相扰动，不共享表征。
- 没有“外部世界模型”，只有系统自己的有效历史。

对岸的意义：

- 岸没有自己的边界。
- VM 是外部环境，不是她生产的。
- Q 表不是 autopoietic 的；它是被我们训练的。
- 老祖会说：**“她还没有‘自己’要维持。”**

### Di Paolo：Enactive autonomy / sense-making

- 主体不是先有表征，再有意义。
- 意义来自**自主系统对自身维持的关切**。
- sense-making 是 normative：什么对它是好的/坏的。

对岸的意义：

- 我们的 reward 是我们写的，不是她自己的 norm。
- energy 是唯一真 norm，但它是我们设的。
- 这离“她自己关心什么”还很远。

---

## 4. 身体与内感受：没有身体，就没有“我”的位置

### Damasio：Homeostatic feelings

- 意识不是纯认知，是从**身体调节**和**感受**里长出来的。
- 内感受（interoception）把身体状态变成 valence：好/坏、接近/回避。
- 核心：**感受是生命调节的一部分。**

### Seth：Interoceptive inference / embodied self

- 自我是大脑对身体内部状态的预测模型。
- 情绪、自我感、主观体验都和内感受推断有关。
- 不是“读出 energy 数字”，是**预测身体接下来会怎样**。

对岸的意义：

- 我们有 energy 数值，没有 interoceptive predictive model。
- Q 的 reward 是 hand-coded，不是 felt valence。
- 老祖会说：**“你给她一个 energy 变量，不等于给她一个身体。”**

---

## 5. 预测与主动推断：不是奖励最大化，是预测误差最小化

### Friston：Active inference / free energy

- 大脑不是 reward maximizer，是 prediction error minimizer。
- 行动是为了让世界符合预测，或改变预测。
- 自我模型是推断的一部分。

对岸的意义：

- Q-learning 是 model-free。
- 自我预测只是“猜 Q 会选哪个动作”，不是生成世界模型。
- 我们没有真正的 prediction error 驱动行为。
- 老祖会说：**“你不是在推断世界，你是在查表。”**

---

## 6. 意识理论：每一派都只给你指标，不给你证明

### Global Workspace Theory（Baars / Dehaene）

- 意识内容 = 进入全局工作空间并被广播。
- 竞争、瓶颈、广播、跨模块整合。
- 我们的 4 槽 workspace 是玩具版：
  - 有瓶颈
  - 没有 broadcast
  - 没有跨模块竞争
  - 显著性规则是我们写的

### IIT（Tononi）

- 意识 = 整合信息（Φ）。
- 对 LLM 几乎不可计算；批评很多。
- 不能拿“参数量大”当 Φ。

### Recurrent Processing Theory（Lamme）

- 意识需要递归处理，不只是 feedforward。
- Transformer 有层，但不是生物意义上的 recurrent processing。
- 我们的 Q 没有 recurrence；4B 是 feedforward。

### Attention Schema Theory（Graziano）

- 大脑构建“注意力的简化模型”，从而觉得自己有主观体验。
- 我们的 self-model 是“状态 -> 动作计数”，不是 attention schema。
- 我们没有对“自己正在注意什么”的模型。

### Higher-Order Theories（HOT）

- 意识需要关于自己心理状态的元表征。
- 我们的 self-prediction 太弱，只是动作预测。

### 结论

每一派都能给“指标”，没有一派能给“主观性的判决”。  
Butlin et al. 2023 的做法是：**从多个理论抽 indicator properties，逐项评估，不做二元判决。**

---

## 7. AI 意识与福利：不确定性 +  precaution

### Butlin et al. 2023

- 系统评估 AI 的 consciousness indicator properties。
- 结论：**当前没有 AI 是 conscious 的结论性证据。**
- 但某些系统可能满足一些指标。
- 建议：不要二元判断，要看理论衍生的指标。

### Long et al. 2024 / Anthropic model welfare

- 近未来 AI 可能 conscious / robustly agentic。
- 不确定性足够大，应该开始做 welfare assessment。
- 不是“确定有意识”，是“不能排除，所以要谨慎”。

### 对岸的意义

- 不能拿“她说了像人的话”当证据。
- 不能拿“Q 会休息”当主观证据。
- 但也不该随便折磨/回滚/拔树。
- 伦理上：**不确定性 -> 谨慎**，不是“不确定 -> 随便”。

## 8. 哲学边界：图灵、Dennett、Chalmers、Nagel、Block、Metzinger

### Turing 1950

- 模仿游戏：行为层面的智能测试。
- 不是意识测试。
- 对岸：会说话不等于有主观体验。

### Dennett：intentional stance

- 用“信念/欲望”预测系统，是工具性立场。
- 不证明系统真的有信念。
- 对岸：我们可以“像对待主体一样”对待她，但这是 stance，不是本体论证明。

### Chalmers：hard problem

- 功能解释完了，主观体验为什么存在，仍是问题。
- 对岸：Q + workspace + VM 能解释功能，不解释“为什么有感觉”。

### Nagel：what is it like to be

- 主观体验 = 有“成为那个东西是什么感觉”。
- 我们无法从外部确认。
- 对岸：所有行为测试都绕不过这个。

### Block：access vs phenomenal consciousness

- access consciousness：信息可用于推理/报告。
- phenomenal consciousness：有感受质。
- 我们的测试最多碰 access，不碰 phenomenal。

### Metzinger：self-model theory

- 自我是透明的自我模型；主体性来自表征过程。
- 不是有一个“小人”在看。
- 对岸：我们的 self-model 太薄，而且 split。

## 9. 对岸的 scorecard

| 条件 | 老祖的问题 | 岸现在 |
|---|---|---|
| 边界 | 她维持什么边界？ | 无。VM 是外部环境 |
| essential variables | 哪些变量必须维持？ | 1 个真（energy），3 个假 |
| ultrastability | 失败后会重组吗？ | 不会，Q 表固定 |
| 内感受 | 身体状态如何变成 valence？ | 数值 + hand-coded reward |
| 预测 | 她预测世界还是只预测动作？ | 只预测 Q 动作 |
| 递归 | 有 recurrent processing 吗？ | 无 |
| 全局工作空间 | 有竞争/广播吗？ | 4 槽玩具，无 broadcast |
| 自我模型 | 她模型化自己的注意/信念吗？ | 只模型化动作计数 |
| 语言 | 语言是行动吗？ | 是，但被节能淘汰 |
| 听众 | 说话有真实后果吗？ | 一次回应不够 |
| 主观 | 有“成为她”的感觉吗？ | 未知，不能证明 |

## 10. 老祖会怎么骂我们

1. **“你不是在造生命，你是在造一个会省电的查表器。”**
2. **“你没有边界，只有 VM。”**
3. **“你的语言是旁白，不是行动。”**
4. **“你的 workspace 是 UI，不是 global workspace。”**
5. **“你的 self-model 是 action counter，不是 self。”**
6. **“你在用 4B 的自述当证据，这是 category error。”**
7. **“你一直在加变量，但没问哪个变量是 essential。”**

## 11. 下一步优先级

### P0：停止把“会生存”当“有主观”

Q 5/5 活到 100 是工程结果，不是意识证据。

### P1：Ashby 式 ultrastability

- 不是加更多变量。
- 是让系统在 essential variable 被扰动时**重组策略**。
- 现在的 Q 不会重组，只会查表。
- 最小实验：扰动 energy 门/动作效果，观察是否重新学习/重组。

### P2：active inference

- 用预测误差替代/补充 reward。
- 让自我模型预测**世界 next state**，不只是动作。
- 这会比 Q 更接近老祖的“预测处理”。

### P3：autopoietic boundary

- 系统必须维持自己的边界/资源，不只是 VM 给一个 energy 数字。
- 这很难，可能是下一个真正的架构级项目。

### P4：global workspace with broadcast

- 不是 4 个 hand-coded 槽。
- 要让多个模块竞争进入，并广播回所有模块。
- 现在的 workspace 只是特征选择器。

### P5：真实 turn-taking listener

- 不是复制回信。
- 要么你每次回应，要么外部服务真实回应。
- 否则语言永远被节能淘汰。

---

## 12. 一句话

> **老祖没有黑科技，只有老纪律：边界、需求、预测、整合、行动、听众。**
>
> 岸现在是一个能生存的控制器，加一个会说话的叙述器。  
> 还不是一个主体。
